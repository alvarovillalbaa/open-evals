  two areas, canonical/nested routes, legacy route attribution, mutually exclusive

  an existing native addon; it performs no installation or fallback download.

  They check unknown trace-ingest commands before file/client/network use,
  retained command help, MCP read/prepare contracts, and authorized410/denied
  Auth paths without reading a payload. They do not establish actual SDK,
  native executable, production Auth, persistence or network behavior.

- Source review checks real catalogue metadata, the existing auth/error paths,
  ready versus empty/unavailable states, current version identities, safe text

  navigation cases for the new contract. They are authored but unexecuted,

## Boundaries

The local source is a selected, Git-hash-verified text overlay, not a full Git
checkout. Its base and candidate hold less than2MiB of regular source; old audit
trees, Git histories, node_modules and build outputs are not copied. Native
`git diff --no-index --check` and bounded whitespace/source checks apply to it.
StorageGuard still prohibits large environments, builds, application servers
and databases locally. The small Node fixture cases and static compilation use
existing tools and create only bounded receipts.

Next16.2.9's installed guides are unavailable in this selected overlay. The
matching official versioned page/layout/Link guides were read without an
installation; redirects follow the exact existing root route pattern. No new
framework API, dependency version or configuration is introduced.

No migration, Auth/access grant, provider secret, account, paid plan, live model,
Harbor execution, campaign execution, release promotion, experiment mutation or
public npm/PyPI publication belongs to this scope. Retiring OTLP preserves its
existing role/scope check and Auth failure response; valid authorized calls
return410 without reading/persisting the body. Existing SDK single/batch wires
and stored evidence remain unchanged.
